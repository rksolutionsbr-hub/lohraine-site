# Lohraine Reink · Landing page

Site público da Lohraine Reink, nutricionista integrativa (CRN-4 24102428).

- `site/index.html`: a página inteira (HTML, CSS e JS), sem build.
- `site/img/`: fotos, logo (verde e branco, extraído do PDF da marca) e imagem de compartilhamento.
- Netlify publica a pasta `site/` (ver `netlify.toml`).
- Formulário de aplicação: Netlify Forms (`aplicacao`). Ative em Netlify > Forms e configure o aviso por e-mail.
- Trechos a confirmar estão marcados com `<!-- PENDENTE -->` no HTML.
